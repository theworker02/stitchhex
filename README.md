# stitchhex

Stitch digests and hex fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/stitchhex/

## Install / run

```bash
git clone https://github.com/theworker02/stitchhex.git
cd stitchhex
node src/cli.js
node --test
```
